# Ayiti Nouvo Kontra Sosyal

A proposal for a new political and economic system for Haiti: citizens chosen by lottery, an expert civil service, independent courts and a public ledger. It aims for no dictatorship and no captured democracy, courtesy to every country without backing down, and a proud, sovereign Haiti.

- `index.html` the interactive five-language page (English, Kreyòl ayisyen, Français, Español, Português), published on GitHub Pages
- `feedback/` the public comment-and-vote site (see `feedback/README.md` for setup)
- `docs/sovereign_fortress_organizational_structure.md` the full 47-part document (English reference text)

It is a proposal for discussion, not legal advice or a governing text. Parts 37 to 47 are the newest and least tested. The translations are machine-assisted and the Kreyòl needs native-speaker review.
