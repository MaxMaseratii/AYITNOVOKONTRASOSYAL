# Ayiti Nouvo Kontra Sosyal

Prepared and built by **Bachelin Max Etienne, MD, MHSc**.

A proposal for a new political and economic system for Haiti: citizens chosen by lottery, an expert civil service, independent courts and a public ledger. It aims for no dictatorship and no captured democracy, courtesy to every country without backing down, and a proud, sovereign Haiti.

- `index.html` the interactive five-language page (English, Kreyòl ayisyen, Français, Español, Português), published on GitHub Pages
- `feedback/` the public comment-and-vote site (see `feedback/README.md` for setup)
- `read.html` the document reader: all 110 Parts inside the site, in English and Kreyòl ayisyen, with a table of contents, search, and downloads for registered readers
- `join/` Konbit 3,5%: the Citizen Card sign-up and a live map of members by commune (only counts are public)
- `gid.html` the movement's training guide (Kreyòl and English)
- `angajman.html` the Citizens' Pledge for candidates (Kreyòl, French, English), printable on one page
- `docs/sovereign_fortress_organizational_structure.md` the full 110-part document (English reference text)
- `docs/ayiti_nouvo_kontra_sosyal_kreyol.md` the full document in Kreyòl ayisyen
- `docs/doc_en.json`, `docs/doc_ht.json` the same text prepared for the reader

It is a proposal for discussion, not legal advice or a governing text. Parts 48 to 110 are the newest and least tested. The main page presents Parts 1 to 47 in detail, plus the Haiti map, the border Line and border markets; every Part is in the reader. The Kreyòl translation of the full document was checked section by section, but only part of it has had a second proofreading pass. It needs review by a native speaker before any official use.
